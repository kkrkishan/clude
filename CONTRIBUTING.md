# Contributing to clude

Thank you for your interest in contributing to **clude**! We welcome all contributions, bug fixes, feature requests, and documentation improvements.

## Development Setup

1. Fork and clone the repository:
   ```bash
   git clone https://github.com/kkrkishan/clude.git
   cd clude
   ```

2. Run the tests:
   ```bash
   npm test
   ```

3. Try out the CLI locally:
   ```bash
   node ./bin/clude.js --help
   node ./bin/clude.js audit
   node ./bin/clude.js stats
   ```

## Pull Request Guidelines

- Ensure your branch is updated with the latest `main`.
- Add test coverage for any new features or bug fixes.
- Follow conventional commit style (e.g., `feat:`, `fix:`, `docs:`, `chore:`).
- Open a Pull Request and detail the problem and your solution.

## Code of Conduct

We are committed to providing a welcoming, inclusive, and harassment-free environment for all contributors.
